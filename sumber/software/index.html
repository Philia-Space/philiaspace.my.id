    Software¶

    Alat untuk belajar dan mining, dikelompokkan per jenis media. Kolom Platform menunjukkan perangkat yang didukung.

    Ikon: disarankan · versi lain dari baris di atasnya · Linux · Windows · macOS · Android · iOS · web · ekstensi browser · skrip mpv · belum pasti. Penjelasan lengkap ada di Keterangan ikon.

    Mining adalah mencari kata baru saat immersion, lalu menyimpannya ke Anki lewat Yomitan. Panduan langkah demi langkahnya ada di menu LazyGuide - Mining dan Setup Mining.

    Semua-dalam-Satu¶

    Satu aplikasi untuk beberapa jenis media sekaligus, lengkap dengan kamus dan pembuatan kartu. Kalau baru mulai, pilih salah satu dari dua aplikasi di tab Disarankan: Manatan kalau kamu banyak membaca manga, Fushi kalau kamu banyak membaca buku atau menonton video. Keduanya punya panduan setup di situs ini.

    SoftwarePlatformKeterangan
    • Manatan
      Platform:
      Keterangan: Anime, manga, dan novel dalam satu aplikasi, dengan OCR instan dan pencarian kamus. Lihat Setup Manatan.
    • Mangatan (1Selxo)
      Platform:
      Keterangan: Versi lain dengan UI ala Mihon, OCR di pemutar video untuk hardsub, dan sinkron dengan Chimahon.
    • Fushi
      Platform: beta:
      Keterangan: Buku EPUB, video, dan audiobook dalam satu aplikasi, satu kamus dan satu statistik. Kamus dan audio dipasang sekali klik. Lihat Setup Fushi.
    SoftwarePlatformKeterangan
    • Chimahon
      Platform:
      Keterangan: Fork Mihon untuk manga dengan OCR, juga bisa novel. Lihat Setup Chimahon.
    • kumahon
      Platform:
      Keterangan: Fork Chimahon yang bisa mengunduh dari situs manga raw dan Nyaa dengan satu klik. Perlu akun Anilist dan Real-Debrid.
    • Kadoki
      Platform: beta:
      Keterangan: Membaca EPUB sambil mendengar audiobook, plus SRT dan dek subs2srs. Kamus dan Anki sudah terpasang di dalamnya.

    Add-on Anki¶

    Cara memasang add-on:

    1. Buka Anki, klik Tools > Add-ons > Get Add-ons...
    2. Salin kode add-on dari daftar di bawah, tempel, lalu klik OK.
    3. Tutup dan buka lagi Anki.

    Kamu bisa memasang beberapa add-on sekaligus dengan menempelkan beberapa kode yang dipisah spasi, misalnya 2055492159 1610304449 1771074083.

    Statistik lama

    Cara memasang JIDict Web di HP (klik di sini)

    Aplikasinya belum ada di Play Store dan App Store, jadi pasang lewat browser.

    Android

    1. Buka jidict.vercel.app di Chrome.
    2. Tekan tombol ︙ di kanan atas.
    3. Gulir sedikit ke bawah, lalu tekan tombol install (Install app atau Add to Home screen).

    iOS

    1. Buka jidict.vercel.app di Safari.
    2. Tekan tombol opsi (garis tiga) di bawah layar.
    3. Tekan Bagikan.
    4. Gulir menu ke bawah.
    5. Tekan Tambah ke Layar Utama.

    Untuk aplikasi kamus seperti EBPocket, GoldenDict, dan e-reader.
